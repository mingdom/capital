## Current State

### Project Understanding
**Domain**: Personal portfolio performance analytics toolkit
**Core Value**: Calculate risk-adjusted returns (Sharpe, Sortino), CAGR, drawdowns, benchmark comparisons
**Data Sources**: SavvyTrader JSON exports, Fidelity CSV performance reports
**Output**: CLI tables, interactive REPL, HTML reports

### Architecture
```
portfolio_cli/
  ├── analysis.py      # Core calculations (pure functions)
  ├── performance.py   # Data loading & normalization
  ├── cli.py          # Typer-based CLI (I/O layer)
  ├── report.py       # HTML generation
  └── shell.py        # Interactive REPL

benchmarks.py         # Market data fetching (yfinance + cache)
sortino.py           # Legacy compatibility layer
```

### Key Design Patterns Identified
1. **Separation of Concerns**: Pure calculation functions in `analysis.py`, I/O at CLI layer
2. **Multiple Data Sources**: Abstracted via loaders in `performance.py`
3. **Caching Strategy**: Benchmark data cached to `data/benchmarks.json`
4. **Backwards Compatibility**: `sortino.py` maintains old API for legacy scripts
5. **Testing Strategy**: Pytest with synthetic fixtures, >80% coverage on core logic

### Dependencies
**Runtime**: pandas, numpy, yfinance, typer, rich
**Dev**: black, ruff, pytest, pytest-cov
**Python**: 3.9+ (targeting 3.11 for modern type hints)
